# Kevin Rojas | Web Developer Portfolio

Professional personal portfolio for Kevin Rojas, a Software Engineering / Computer Engineering student, freelance web developer and adventure tour guide based in San Carlos, Costa Rica.

The site presents a modern profile that connects web development, UI/UX, real-world tourism experience, nature and practical projects.

## Live Site

https://kevin-portafolio-lovat-five-83.vercel.app/

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Main Portfolio Sections

- **Hero** — professional introduction, value statement and calls to action.
- **About Me** — personal background connecting technology, tourism and practical field experience.
- **What I Do** — web development, UI/UX responsive design and adventure tourism / real-world projects.
- **Education** — academic path and technical learning background.
- **Experience / Certifications** — web development certificate, sustainable tourism and La Vieja Adventures experience.
- **Projects** — modern project cards with descriptions, technologies, Live Demo and GitHub links.
- **Adventure, Nature & Field Experience** — places and outdoor experiences that inspire the portfolio identity.
- **Contact** — direct email, phone, location, social links and a validated contact form that prepares an email message.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

## Customization Notes

- Update project links in `data/projects.ts`.
- Update social profile URLs in `data/social.ts`.
- Add a CV file to `public/Kevin-Rojas-CV.pdf` to activate the Download CV button.
- Replace the hero initials placeholder with a personal image when available.
